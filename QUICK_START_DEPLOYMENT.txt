🚀 DEPLOY IN 5 STEPS
────────────────────────────────────────────────────────────────────────────

STEP 1: Create GitHub Repo
────────────────────────────────────────────────────────────────────────────
→ Go to https://github.com/new
→ Repository name: leads-crm
→ Create repository


STEP 2: Push Code
────────────────────────────────────────────────────────────────────────────
In terminal, run (replace YOUR_USERNAME with your GitHub username):

  git remote add origin https://github.com/YOUR_USERNAME/leads-crm.git
  git branch -M main
  git push -u origin main


STEP 3: Deploy to Vercel
────────────────────────────────────────────────────────────────────────────
→ Go to https://vercel.com/new
→ Sign in or create Vercel account
→ Click "Import Git Repository"
→ Select leads-crm
→ Click "Import"


STEP 4: Add Environment Variables
────────────────────────────────────────────────────────────────────────────
On Vercel import page, add these two variables:

  Name: NEXT_PUBLIC_SUPABASE_URL
  Value: https://qwwweztgjhrpbkcirsbm.supabase.co

  Name: NEXT_PUBLIC_SUPABASE_ANON_KEY
  Value: sb_publishable_AimbCYbbGwWZyOJ8iR2XeA_bcB_dqNO


STEP 5: Deploy
────────────────────────────────────────────────────────────────────────────
→ Click "Deploy" button
→ Wait for build to complete (2-5 minutes)
→ Click deployment URL to verify it works


🎉 DONE! Your app is now live! 🎉

🆘 NEED HELP?
────────────────────────────────────────────────────────────────────────────
Common issues:

  ❌ Build fails?
     → Check Vercel build logs
     → Verify env variables are correct
     → Try "Redeploy" in Vercel dashboard

  ❌ Login doesn't work?
     → Confirm Supabase keys in Vercel settings
     → Check Supabase project is active

  ❌ Can't push to GitHub?
     → Verify GitHub repo exists
     → Check SSH keys are configured (or use HTTPS)
